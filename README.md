# YouthAura Labs — Next.js Web Platform

A high-performance web platform for **YouthAura Labs** built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Features

- **Pixel-Perfect Modern Design**: Replicated and enhanced with custom OKLCH color tokens, glassmorphism, animated ember glow, and infinite marquee ticker tape.
- **Next.js App Router**: Optimized server and client components with dynamic SEO metadata, OpenGraph cards, and Google Fonts (`DM Sans` and `Space Grotesk`).
- **Complete Page Architecture**:
  - **Landing Page (`/`)**: Hero section with metric counter cards, marquee ticker ribbon, capability feature breakdown, featured tracks, voices/testimonials, interactive FAQ accordion, and cohort CTA.
  - **About (`/about`)**: Origin story, Vision & Mission, 6 Core Values, Founder bio block, and Future Vision roadmap.
  - **Programs (`/programs`)**: 6 program pillars, 4 mandatory core modules, 10 specialization tracks with career outcomes, and 4-step application pathway.
  - **Community (`/community`)**: 6 community pillars, private WhatsApp circle callout with direct invite trigger.
  - **Contact (`/contact`)**: Interactive inquiry submission form, email and location details, social channels.
  - **Apply (`/apply`)**: Comprehensive 4-stage cohort application form with track selector chips, file attachment picker, validation, and confirmation feedback.
  - **Auth & Admin (`/auth` & `/admin`)**: Admin authentication portal and candidate management dashboard with real-time search, track filtering, status counters, and review actions.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: `DM Sans` (body) & `Space Grotesk` (display headings)

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
